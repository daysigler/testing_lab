Bienvenido a la prueba de A11y Studio

Sobre esta página

Esta es una página de prueba diseñada para verificar que el A11yDetector puede analizar correctamente un sitio con suficiente contenido visible. Contiene varios párrafos, encabezados de diferentes niveles y algunos elementos interactivos.

El objetivo es que el escáner encuentre los errores de accesibilidad que hemos colocado intencionadamente y que el Resolver (Solver) pueda generar las correcciones oportunas.
